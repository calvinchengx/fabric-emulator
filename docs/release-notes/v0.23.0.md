# v0.23.0

## `sc` and `spark._jvm` now work on the default engine, for what people actually use

- **The measured subset of the RDD/JVM surface is emulated instead of refused.**
  Spark Connect exposes no `SparkContext` and no JVM bridge on **any** engine —
  Apache's own Connect server included — so this was never a Sail gap to wait
  out. Until now the agent bound `sc` to a stub that refused everything, which
  meant a notebook doing the one thing Microsoft's own docs demonstrate failed
  here and worked in production: a fidelity inversion, and the only one in this
  repo pointing that direction.

  What is emulated was **measured, not guessed**
  ([docs/50](../50-rdd-usage-capture.md)): four corpora — the notebooks we ship,
  contoso-data-platform, `microsoft/fabric-samples` and
  `MicrosoftDocs/fabric-docs` — and the entire `sc`/`_jvm` surface in use turns
  out to be **logging plus one four-element smoke idiom**. Nobody computes with
  RDDs. So the facade covers `sc.setLogLevel`, `sc.parallelize(...)` with
  `map`/`filter`/`collect`/`count`/`sum`/`toDF`, and
  `spark._jvm.org.apache.log4j` — bound on both spellings Fabric offers, the
  bare `sc` global and `spark.sparkContext`.

  **It is eager, local, and says so.** `parallelize` refuses above 10,000
  elements rather than pose as a distributed engine, and every unmeasured API
  (`textFile`, partition-level operations, accumulators, broadcasts, `java.*`)
  raises a pointer to the JVM overlay, which still provides the real thing. A
  facade that quietly accepted a million rows would work slowly, differ silently
  and tell nobody — the pattern this project keeps removing.

  **The expectations are not self-asserted.** `spark_agent/rdd_contract.py`
  holds each idiom and the answer it should give; the unit tests assert them
  against the facade, and `e2e/spark-jvm` evaluates the *same snippets* against
  a real Apache Spark 3.5 JVM in CI. Unit tests prove the facade matches the
  contract; the JVM job proves the contract matches Spark. Either alone would
  only prove the author was consistent with themselves.

  **Nothing that worked before changes.** JVM sessions keep their real
  `SparkContext` — the facade is only bound where there was previously a
  refusal.
